# 627-3 — A node receives the space ready

**What is built.**
- Graph element (`Fractera/fractera-graph-lightrag-starter`): the door `POST /api/graph-space-import` `{ space, file, sha256 }`
  (node key, loopback). It checks the sha256 and that `manifest.model` and `manifest.dims` equal the node's `embeddings`, unpacks into a
  new folder, then swaps it for `spaces/<space>/` by a rename; the previous space stays until the swap succeeds. README, «Spaces».
- Core: `scripts/catalog/install.mjs`, called by `npm run services:install` and by the node's update: when the node does not hold the
  package named in `lib/agent-kit/skills/catalog/release.json`, it downloads it and calls the door.

**Done when.** A fresh install brings the space «skills-catalog» with no marking and no vector counted on the node.

**How it is proven.**
1. A fresh install on the Mac → `graph-query { space: "skills-catalog", … }` answers; `embeddings` `GET /api/embed-status` `calls`
   did not grow during the import (nothing was counted).
2. The network turned off after the install → the same query still answers.
   Negative controls: a package with a wrong sha256 → refused, the old space unchanged; a manifest with another model → refused by name.

**Rests on.** 627-2.

**Not in it.** Who reads the space (627-4).
