# 627-5 — Census and the full run (after the owner's yes with the pilot's numbers)

**What is built (core).**
- `scripts/catalog/census.mjs`: the list of skills with 1,000 installs or more. The method is chosen in 627-1 and written there: a sweep
  of `npx skills find` over a topic vocabulary, deduplicated, or the skills.sh API with a Vercel OIDC token if the owner provides one.
- Then fetch → mark → build → pack → release; `lib/agent-kit/skills/catalog/release.json` points to the new package.

**Done when.** The release holds every skill of the census, minus duplicates and refusals — each of them counted.

**How it is proven.**
1. The manifest's count equals census − duplicates − refusals (the three numbers in the summary).
2. 20 random cards read against their `SKILL.md`.
   Negative control: 5 known spam copies are absent.

**Rests on.** 627-4, and the owner's yes on the count, the time and the cost measured in 627-1 — asked in the choice window with those numbers.

**Not in it.** Skills from sources that are not GitHub.
