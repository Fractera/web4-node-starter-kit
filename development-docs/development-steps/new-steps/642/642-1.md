# 642-1 — Elements: the terminal under the row, live

**What is built.** `deploy-board.client.tsx`: while a deployment runs, the board asks `?progress=1&log=<current>` every second (the door
exists, 353-3) and opens `LiveLog` under the row being built; rows waiting in the queue say «в очереди». When the element is done, its
terminal stays with the last lines and a closing line (green «развёрнут за N с» / red «не развернулся»), with «Скрыть».

**Done when.** «Развернуть» on an element on the owner's node opens a moving terminal under its row and leaves the result under it.

**How it is proven.** 1. happy-dom over the real board with a stub door (as `p641/probe-641.mjs`): running → the terminal under that
row only, its lines follow the door, the scroll holds the last line; done → the result line stays. Negative control: no deployment →
no terminal. 2. Live on the owner's node: one element deployed from the board; the progress door answers each second with new lines
(its log file grows) and the page shows them.

**Rests on.** 353-3. **Not in it.** The core; retries.
