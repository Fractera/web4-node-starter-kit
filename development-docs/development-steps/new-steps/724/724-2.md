# 724-2 — the instruction: the laws of looking

**What is built.** CLAUDE.md §6, five lines (wording for the owner's yes), then `npm run check:instruction -- --seal`:

- A look that returned nothing is not a look: an empty output, `None`, a timeout, a skipped file — find why before going on.
- A guard is read by its exit code — never through a pipe or a `tail` that hides it.
- An interface of the core is built with `interface-design` and the ready parts (`use-tools`, `use-chat`, sections) found BEFORE the first
  line and named in the plan; «built» only after every new or changed surface is seen by `npm run eyes` in each of its modes (full and
  compact menu, with and without JavaScript, 1440 and 390) and the screenshot paths are in the summary.
- A plan's «what exists» is measured in the code before any variant reaches the owner.
- At a blind spot about the node — the soul's rule: depth, cost now and later, weigh, the fix or its step, in the same answer.

**Done when.** The lines are in §6 and the seal matches.

**Proven by.** Plane 1 — `check:instruction` green after the seal; negative: the text changed without a seal → `===INSTRUCTION_FAIL===`.
Plane 2 — the node's CLAUDE.md after the update carries the lines and a session start shows them (the owner's node is not restored, so
the file itself is checked).

**Rests on.** 608 (the seal), 720 (the owner's node). **Not in it.** Hooks and guards that enforce the lines (725).
