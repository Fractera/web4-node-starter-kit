# 643-1 — The main agent's first contact: name, address, style, language

**What is built.** `know-the-architect` «First contact»: one message, any question can be skipped —
1. how to call you, and «ты» or «вы»;
2. short and straight, or detailed and warm;
3. what you are building, or want from the node now;
4. the project's language — the one its pages are written in first; and whether other languages are needed now. The price is said in
   the same line: every language is translated, checked and kept up on every change, so each one makes the work longer and dearer;
   more languages can be added later at any time (skill `expand-site-language`);
5. anything never to do or touch.
The answers are saved as said (`user`, `feedback`). The language set is changed only after the person's yes, through `POST /api/config/
languages`, with the rebuild named (minutes, the pages stop for it).

**Done when.** A fresh main agent asks all of this in one message on the first «привет», and only once.

**How it is proven.** On the Sonnet bench (643-3).

**Rests on.** — **Not in it.** Translating anything; changing the language without the yes.
