# 643-2 — The two modes and how not to be blocked: the welcome and the first contact

**What is built.** In `scripts/launch.mjs` `welcome()`, in both languages, a new point «РЕЖИМЫ РАБОТЫ И ВАША ПОДПИСКА»:
- **Строительство** — you build the elements (the node's microservices) with their agents: this is ordinary work in the unmodified
  Claude Code on your own subscription — the case Anthropic permits;
- **Workflow** — the built tools do tasks by themselves, on a schedule or in the agents' chats: automated access is allowed «via an
  Anthropic API Key or where we otherwise explicitly permit it», and the subscription's limits assume ordinary, individual use; Anthropic
  names no threshold — the more automatic work on the subscription, the higher the risk (a warning, limits, the account closed, money
  not returned); the reliable way is an API key for this mode (step 638).
The same in two sentences once at the main agent's first contact (`know-the-architect`), pointing to `provider-rules`.
The words follow the owner's answer on the grey zone and on the end of his message («В любом случае…»).

**Done when.** The welcome carries the point in both languages, every claim backed by a quoted source of `provider-rules`.

**How it is proven.** 643-3; and `node scripts/launch.mjs`'s `welcome()` printed alone (a dry print, nothing installed).

**Rests on.** `provider-rules` (629). **Not in it.** The API key itself (638); any change to the sealed instruction.
