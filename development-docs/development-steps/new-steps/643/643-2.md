**What is built.** In `scripts/launch.mjs` `welcome()`, in both languages, a new point «РЕЖИМЫ РАБОТЫ И ВАША ПОДПИСКА»:
- **Строительство** — you build the elements (the node's microservices) with their agents: this is ordinary work in the unmodified
  Claude Code on your own subscription — the case Anthropic permits;
- **Workflow** — the built tools do tasks by themselves, on a schedule or in the agents' chats: this is the grey zone — Anthropic's terms
  allow automated access to the subscription only where they explicitly permit it, and the plans' limits assume ordinary, individual
  use; Anthropic names no threshold — the more automatic work on the subscription, the higher the risk (a warning, limits, the account
  closed, money not returned). The automatic work of the tools themselves (text, images, speech, vectors) goes through the node's
  OpenAI key (the page «Переменные окружения»). **Never an Anthropic API key** — the owner's ban (643-main §1).
