thinks: «pain, not death» (skill fractera-vs-anthropic). The wish: «almost no pain» — Claude stays the main engine (its new models are a

## Substeps (proposed; each with two proofs, one negative)

- **860-1 · The switch per agent (folds 690).** Every session carries its engine — the main agent, an element's agent, a work session:
  passport field `engine`, a Pult button next to model and effort. Engines only lawful: Claude Code on the person's subscription; Codex on
  the person's subscription; a local model behind an OpenAI-compatible door (Ollama, llama.cpp or analogue — chosen by measurement). The
  law stays: an Anthropic API key is never proposed. On a switch the agent gets one line: which engine and what it can do; on a weak
  engine it takes no code («this waits for a strong engine»).
- **860-2 · The spare heart — a small local model for simple decisions, no code.** Candidates by measurement on 8 GB CPU: the purpose of a
  person's message (the node's hard commands), routing an incoming bot message (whose, urgent, question or task), one line from logs for
  `where` / `serve:status`, a second cleaning pass of 855 reports (names in domains, chat ids the regex missed), the deep memory's thinking
  without an OpenAI key and with the subscription's limit spent. Each place — one door with one key (skill use-ai-generation), pointed at
  the local model as the spare.
- **860-3 · Survival when the provider falls.** The node notices the engine is unavailable (refusal, block, limit) and says one line in
  Telegram: what stopped, what works. Agents' tasks are not lost — queued «waits for the engine», started when it returns or the person
  switches. Nothing switches by itself (the law: no behaviour nobody ordered).
- **860-4 · Measurement, not promises.** `npm run engine -- bench`: which local model fits, its memory, seconds per typical request,
  accuracy on 50 real node phrases. The person sees the numbers and decides; a resident model process is named with its memory price and
  sleeps / wakes on demand like the deep memory.
- **860-5 · The strong road is a machine, not architecture.** For local thinking at code level — a GPU machine; one line of advice with
  its price in skill dedicated-server.
- **860-6 · The proof that the heart has no owner.** Cut the provider on a test node: the product works; the person gets one line; hard
  commands are recognised locally; agents' tasks wait and start after the return; 855 keeps cleaning reports.
