# 663-7 — the installer weighs the computer before it starts (plan)

**The owner, 2026-11-06, verbatim:** «Может случиться так что тебя вообще будут пробовать установить на компьютере, где недостаточно памяти в
принципе например перегруженный компьютер у которого 4 ГБ оперативной памяти прямо на таком компьютере лучше даже не начинать установку а
это значит что нужно куда-то в инструкцию добавить проверку. На компьютере у которого есть шесть или 8 ГБ нужно предупредить что для работы
архитектуры придётся жёстко ограничить использование любых других приложений одновременно. Придётся закрыть браузер и другие активные
процессы. Если это сделать невозможно то лучше прервать установку. На архитектуре 16 ГБ также в начале установки следует проверить
достаточно ли свободный оперативной памяти и если её меньше 3 ГБ то порекомендовать в процессе установки ограничить или прекратить
использование избыточных приложений. Я так понимаю это те процессы которые должны выполняться на уровне установщика Claude Code Agent так
как сейчас проверяется например является ли Fork оригинальным … Это все в рамках этого же задания добавляет в план».

**Measured.** `scripts/launch.mjs` — step 1 `check-local.mjs` (this computer, no other node), step 3 `check-origin.mjs` (the fork); the
node itself weighs 2054 MB in 28 processes on the owner's Mac (before 663-6), the first build needs more (a Next.js build per element).
The instruction's install block says «npm run launch … with no questions».

**Built.** `scripts/check-memory.mjs` — step 1 of `launch.mjs`, right after `check-local`: total memory (`os.totalmem()`), available
(`lib/free-memory.cjs`):
- total < 6 GB (the owner's 4 GB) → `===LAUNCH_FAILED===` «на этом компьютере N ГБ памяти — узлу этого мало; лучше не начинать: нужен
  компьютер или VPS от 8 ГБ» (the consultation of §6, never a silent try);
- 6 GB ≤ total < 12 GB (the owner's 6 and 8) → `===LAUNCH_ASK===` with the words «закройте браузер и другие приложения на время
  установки и работы узла; если это невозможно — установку лучше прервать»; the install agent relays them and waits for one word: ready →
  `npm run launch -- --memory-ok` continues; impossible → it stops and says how to come back;
- total ≥ 12 GB (the owner's 16) and available < 3 GB → a `===PROGRESS===` warning «свободно N ГБ — на время установки закройте лишние
  приложения», the install goes on.
The instruction's install block (sealed, the owner's word given in this message) gains `===LAUNCH_ASK===`: the only question the install
agent may ask. The thresholds live in one place (`lib/free-memory.cjs` constants) and are the same the rule of 663-3 names in its alarm.
**Done:** a weak computer is refused before anything is installed, a middle one only with the person's word, a strong one is warned when busy.
**Proven:** lab — `check-memory.mjs --total 4096` → FAILED with the words; `--total 8192` → ASK, and `--memory-ok` → OK; `--total 16384
--free 2500` → the warning and OK; `--total 16384 --free 6000` → OK silently (negative control); a real run on the owner's Mac (16 GB) →
OK. `check:instruction` green resealed.
**Not in it:** measuring the CPU or the disk.
