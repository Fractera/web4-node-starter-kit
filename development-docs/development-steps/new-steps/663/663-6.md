# 663-6 — one shared health watcher instead of one per element (plan)

**Built.** `scripts/health-watch.mjs` learns `--all`: one process `fractera-health-watch` checks every running element in turn with the
same patience (several failures in a row before a restart, the cold-compile allowance kept), re-reading the registry so a sleeping element
is skipped and a woken one is watched; `ecosystem.config.cjs` builds this one instead of `fractera-svc-<id>-watch` × 13; `serve:*`,
`node:update` and the installer stop and start it. The old per-element names are removed on the next `serve:start` (pm2 delete).
**Done:** the node keeps the same protection against «process alive, site dead» for about 600 MB less.
**Proven:** on the node `pm2 jlist` before/after (expected ~−600 MB); lab — an element made to answer 500 is restarted after the same
number of failures as before (negative control: one slow page does not restart it).
**Rests on:** 232-3 (the watcher's patience).
**Not in it:** watching the core itself (it has its own `fractera-web4-watch`).
