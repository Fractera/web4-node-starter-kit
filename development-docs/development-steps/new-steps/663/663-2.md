# 663-2 — `npm run load`: what the node weighs and what sleep would cost (plan)

**Built.** `scripts/load.mjs` (core), `npm run load [--json]`: available memory (`lib/free-memory.cjs`), the node's processes from
`pm2 jlist` grouped per element (server + its watcher, or the shared watcher after 663-6), each element's class (663-1), and the cost of
its sleep: the next calendar entry (`data/cron.json` of the element), visible in the Web4 network (`element-web4.cjs`), a public address
(own domain / zone), the elements that depend on it (embeddings ← vectors, graph, memory; by their passports' links). No model, no timer.
**Done:** one command answers «how much is free, who weighs what, who may sleep and what we lose».
**Proven:** on the owner's node — the totals equal `pm2 jlist` (negative control: a stopped element shows 0 MB and «asleep»); `--json`
parsed by the rule's lab.
**Not in it:** decisions (663-3).
