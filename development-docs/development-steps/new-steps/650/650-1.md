# 650-1 — spaces in the deep memory (memory element v2.2.21)

**Repository:** `Fractera/fractera-memory-starter`, `main`, then the tag v2.2.21.

## What is built
- `lib/memory/source.mjs` — `spaceOf(path)`: `build` / `core` → the main agent (every space); an element id → that id. The 🛑 rule of
  2026-09-16 is replaced by the owner's words of 2026-11-05 (650-main D1).
- `lib/memory/door.mjs` — every verb gets the caller's space. The GET verbs (`journal`, `sources`, `signals`, `objects/{id}`,
  `objects/{id}/file`) take `?from=`; without it — 400 `source-required`, never «all». `DELETE /v1/journal` — an element: its own space;
  the main agent: `node` unless `space` is named (D3). `contract.mjs` declares `from` on them; the contract version goes up.
- `lib/memory/messages.mjs` — column `space TEXT NOT NULL DEFAULT 'node'` by the late-column path, index `(space, id)`; every insert
  writes it; existing rows stay `node` (D2).
- Vectors — `said-vector.mjs`, `feedback-vector.mjs`, `fractera/objects.ts`: a collection per space — `memory-said`, `memory-feedback`,
  `memory-objects` for `node`, `…--<element id>` for an element; a search goes to its own collections; the main agent's — to `node` and
  every element collection the table knows (`SELECT DISTINCT space`).
- Graph — `node.mjs`: `memory` for `node`, `memory-<element id>` for an element (the graph's rule ≤ 32 characters, checked against the
  element ids of the registry; an id that does not fit — a refusal, never the shared space).
- The verbs that read — `verbs.mjs` (remember, recall), `read.mjs` (`askGraph`, `filterObjects`, `knownLabels`, `namesIn`),
  `chain-links.mjs`, `journal-verbs.mjs`, `sources.mjs`, `signals.mjs`, `feedback.mjs` (an answer of another space — refused),
  `object-verbs.mjs`, `fractera/objects.ts` (`ingest`, `fileOf`): filtered by the space.
- `README.md` — section «Spaces»; the answer to the main agent names the space of each finding (`source_path` already carries it).

## Done when
A phrase said from element A answers A and the main agent, and on every verb nothing to element B.

## How it is proven (named in advance)
1. **Doors, on the owner's node** (memory on): `remember` from `["root"]` (A) of a phrase no one said before («у Ани в шкафу синий зонт
   650»); `recall` from A → found; from `["blocks"]` (B) → not found (**negative control**); from `["build"]` → found, «root» named;
   `GET /v1/journal?from=blocks` — no such line, `?from=root` — the line; A's object from B → 404; `DELETE /v1/journal?from=blocks` → A
   still recalls it; any GET verb without `from` → 400.
2. **The stores**, by the data layer and the graph directly: the row has `space = 'root'`; the search in `memory-said--root` finds the
   phrase, in `memory-said` — not; `graph-query` in `space: memory-root` knows «Аня», in `space: memory` — not.

## Rests on
Graph spaces (596-1), partitioned vector collections (vectors v1.2.5), the late column of `messages.mjs`, `parseSource` against the
registry.
