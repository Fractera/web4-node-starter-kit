# 726-1 — the ledger in the core: every outside call writes one line

**What is built.** `lib/usage-ledger.cjs`: `record({ who, provider, endpoint, model, tokensIn, tokensOut, status, code, message, ms })`
appends one JSON line to `data/node/usage/<YYYY-MM-DD>.jsonl` (outside git; never a key, a prompt or personal data; the provider's own
error code and message kept so a cause is never guessed again). `outbound(provider, who, fetchArgs)` wraps a call and records it. Every
core call site uses it — the agent kit's `translate.cjs` master, then `agent-kit:update` to its copies; the doors and the tools listed in
the plan; the AI SDK calls through its `onFinish`/error path (checked in `node_modules/ai/docs` first). `npm run money [--day] [--who]` —
today by consumer and provider, the errors with their codes.

**Done when.** No call to an outside service leaves the core without its line.

**Proven by.** Plane 1 — a test against a fake OpenAI server on a spare port: a 200 with `usage` → one line with tokens; a 429 with
`{ error: { code: 'rate_limit_exceeded' } }` → the line carries that code; negative control: no key → no call and no line; a guard
`check:outbound` — a `fetch('https://api.openai.com…` outside the ledger module is red. Plane 2 — on the owner's node one translate call:
the line appears and `npm run money` names the translate door; today's 429 explained by its own code the next time it happens.

**Rests on.** `openAiKey()`. **Not in it.** Elements (726-2), a page (726-3).
