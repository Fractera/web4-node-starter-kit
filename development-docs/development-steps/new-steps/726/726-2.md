# 726-2 — the elements' ledger

**What is built.** The same module in the custom and native templates and root, writing into the element's own data folder
(`data/services/<id>/usage/…`, the folder the core already reads); its guard `check:outbound` in each template; releases, pins, rollout
(`release-template`). `npm run money` merges the core's and every element's journals.

**Done when.** A call made by an element is seen by the core without the element's agent.

**Proven by.** Plane 1 — each template's test with the fake server and the guard, CI green. Plane 2 — on the owner's node the deep memory
parses one phrase with the key: its line appears under `memory` in `npm run money`; negative: an element turned off adds nothing.

**Rests on.** 726-1. **Not in it.** Providers that are not called over HTTP by our code.

## Measured 2026-11-12 in the autonomous run — STOPPED before code, waiting for the owner

- Every one of the 15 templates calls OpenAI directly in 5 files: `_tools/tool-voice-input/server/transcribe.ts`,
  `_tools/tool-fact-draft/server/draft.ts`, `_tools/tool-socials-ai/server/resolve.ts`, `app/api/i18n/translate/route.ts`,
  `scripts/snippet-background.mjs`; memory adds `lib/data-store/context.mjs`, storage one more. The templates' tool copies have already
  drifted from the core's (`transcribe.ts` has no `language` of 617), and no script syncs them — so 726-2 is a hand port into 15
  repositories, 15 releases and pins, then a rollout that rebuilds every element.
- The agent kit already writes each element's ledger (`<element>/data/node/usage/`, `agent-kit/translate`), and «Все подписки» reads it.
- Why stopped: the owner's own order of 717 — «сначала тестируем кастомный элемент потом когда тесты пройдут создадим нативный элемент
  с такими же изменениями. То что касается других существующих элементов обсудим это позже». A night rollout rebuilding every element of
  the owner's node without him is the opposite.
- Proposal: (1) the custom template as the pilot — `lib/openai-error.cjs` + `lib/usage-ledger.cjs` byte-identical to the core's, the 5
  callers through them, its own `check:openai-calls`, a release and a pin; (2) the same in the native template; (3) the rollout to the
  existing elements after his word. Optional first: one script that syncs `_tools` from the core into a template, so the drift ends.
