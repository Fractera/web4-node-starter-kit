# 726-2 — the elements' ledger

**What is built.** The same module in the custom and native templates and root, writing into the element's own data folder
(`data/services/<id>/usage/…`, the folder the core already reads); its guard `check:outbound` in each template; releases, pins, rollout
(`release-template`). `npm run money` merges the core's and every element's journals.

**Done when.** A call made by an element is seen by the core without the element's agent.

**Proven by.** Plane 1 — each template's test with the fake server and the guard, CI green. Plane 2 — on the owner's node the deep memory
parses one phrase with the key: its line appears under `memory` in `npm run money`; negative: an element turned off adds nothing.

**Rests on.** 726-1. **Not in it.** Providers that are not called over HTTP by our code.
