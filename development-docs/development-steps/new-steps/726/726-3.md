# 726-3 — Dashboard «Все подписки»

**What is built.** A page of the dashboard (a data folder, ready parts found by `parts_find` — 725): a row per outside service from every
element's `SUBSCRIPTIONS.json` and the ledger's providers; a dropdown of the elements that call it; its state — a key set or not, the last
call and its result, the last error with the provider's code and time; links to each element's «Подписки» page.

**Done when.** The owner sees every paid service of the node and who uses it on one page.

**Proven by.** Plane 1 — the page's data function over a fixture (two elements, one shared service) → one row with both; negative: an
element without subscriptions and calls → absent. Plane 2 — eyes on the owner's node: 1440 and 390, JavaScript on and off, the screenshot
paths in the summary (725-4).

**Rests on.** 726-1/2, 725. **Not in it.** Balances (726-4).
