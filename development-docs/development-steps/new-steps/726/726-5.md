# 726-5 — the skill of the answer: where the money goes, and the balance offer

**What is built.** A core skill `money-and-resources` with `npm run money` (726-1) and `npm run money -- --balances` (726-4): «за что
уходят мои деньги?» answered from the journal in plain words (who, what, how much, the errors); «как дела у проекта?» (`npm run where`)
ends with one offer to check the balances; a line at a session start only when something is red (a budget crossed, a provider refusing).

**Done when.** Both questions are answered without a model and without reading a key.

**Proven by.** Plane 1 — the skill's commands over a fixture; negative: an empty journal → «расходов не было», no invented numbers. Plane
2 — the owner asks in Telegram «за что уходят мои деньги» and gets the answer from the journal.

**Rests on.** 726-1…4, 724-1 (the blind-spot rule). **Not in it.** —
