# 726-6 — the recommended services with the owner's links

**What is built.** A checked list of services (what each is for, our honest verdict, the link), offered by `shape-the-need` and
`create-element` when a person is about to build a service of that kind (the owner's example: an AI search → Exa.ai instead of Google).
Three decisions are the owner's before any code:
1. **Disclosure.** My recommendation: the link is named as a referral that supports Fractera — honest to the person, and many advertising
   laws require disclosing a paid connection (the primary sources checked and quoted here first).
2. **Home.** In the core's git it ships to every node but is public (the core is open source); in the node's data it is private but only
   on this node; fetched from a Fractera address it is a single point of failure (the node's law).
3. **Order of the offer.** A recommended service first only when it fits the need on merit — never against the person's need.

**Done when.** A need for a service of a listed kind brings one honest line with the link.

**Proven by.** Plane 1 — `shape-the-need` over a fixture need «поиск в интернете для агента» → the line with Exa.ai and the disclosure;
negative: a need no listed service fits → no recommendation. Plane 2 — a live conversation on the owner's node.

**Rests on.** 726-5. **Not in it.** Any hidden placement of a link.
