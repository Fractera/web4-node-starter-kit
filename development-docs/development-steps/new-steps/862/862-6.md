## The decision (mine, by the greatest good; routed as substep A of 862 — the same capability)

One map of three sides — **the client** in every project, **the core** (the window, the signed talk, the install), **the store** on
fractera.ai — told in four lenses, each only what its reader acts on, each naming the contract version (862-0, v1):

1. **The core** — `.claude/skills/marketplace/SKILL.md` (the main agent): the whole map, the ladder's Fractera rung, the payer's window,
   the pull of the order status, the install, the applications, what is simulated (Lagrix), the money rules (one payment per cart,
   free starters without paying, no refund unless the law, a failed install repeated free), R-01…R-05. `handle-need` and
   `use-i2i-a2a-f2f` point to it instead of keeping their own marketplace text.
2. **Every element — native and custom** — `build-skills/skills/use-marketplace/SKILL.md` in both templates: as a buyer, a missing hand
   is `need` and its answer is «recommended, waits the person» — never buy, install or call the store; as an author, an own native
   offers itself on «Предложить в маркетплейсе» or by `npm run market:offer`, a custom element does not (Roma, 854); what a starter is
   (R-01, R-02). It replaces the custom template's old `use-f2f`.
   **One source, no drift:** the text lives once in the core (`lib/instructions/element/skills/use-marketplace.src.md`) and `npm run
   instruction:element -- templates` writes it into both templates with the instruction; the builder refuses a template whose copy
   differs. Born elements take it by the template road (859: `npm run template -- offer`).
3. **The client element** — its own skill in its repository: its doors, its data, its pages, its bot.
4. **The store** — the same map from the store's side, sent with the contract to fractera.ai; lidt5's agent keeps it in its own skills.

Triggers in every lens's description: a need nobody here covers, «найди стартер», «купить», «продать / предложить свой элемент», «как
работает маркетплейс», a price, a refund, an install of a bought starter.
