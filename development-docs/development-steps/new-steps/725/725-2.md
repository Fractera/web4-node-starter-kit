# 725-2 — `parts_find`: the tool in hand in every build session, and `npm run parts`

**What is built.** A second tool in `lib/agent-kit/skills/mcp.mjs`: `parts_find { query, terms }` — words over `PARTS.json` plus meaning
over the node's vectors (collection `node-parts`, indexed like `self-description` — only changed cards re-embedded) plus the graph: every
part an entity linked to its users (`npm run parts-base`, loaded with `skills-base` at install and update). It answers up to five parts:
name, kind, path, how to use, who uses it, what it replaces — or «nothing ready; build it, then give it a card». `npm run parts -- <words>`
prints the same for scripts and the person. The instruction's §8 line: «an interface piece — `parts_find` first». Each call writes a
session marker (`logs/parts-asked/<session>.json`) for the gate of 725-3.

**Done when.** A build session lists the tool and gets the right part for plain words in Russian and English.

**Proven by.** Plane 1 — a test over the map: «поле с голосом» → `VoiceTextarea` first; «окно переписки с моделью» → the chat tool;
«левое меню» → the workspace shell; negative: «бронирование столика» → nothing ready. Plane 2 — a live session on the owner's node: the
tool is listed beside `skills_find`, the same four answers.

**Rests on.** 725-1, `embeddings`, the graph. **Not in it.** The gate (725-3).
