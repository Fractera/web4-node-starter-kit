# 725-5 — the elements: the same map, tool and gate in every template

**What is built.** In the custom and native templates and root: the parts map of the element (its `_tools/TOOLS.json`, its own sections,
its composites with cards), `parts_find` answering from the ELEMENT's map in an element session (the session's folder decides), the gate
hook in the element's settings, `check:parts-map` and `check:parts-use` in its prebuild; a release of each template, the pins in the core,
the rollout to the node's elements (skill `release-template`).

**Done when.** An element agent cannot create an interface file blind and finds its own parts.

**Proven by.** Plane 1 — each template's prebuild green, the hook samples green, CI three-os green on every release. Plane 2 — on the
owner's node an element session (Клип) asks «поле с голосом» and gets its own `voice-control`; a blind new file is refused.

**Rests on.** 725-1…3. **Not in it.** Rebuilding an element's existing duplicates (its own agent's work after the sweep).
