# 725-4 — the craft in the flow: `interface-design` for the panel, the surfaces seen in the summary

**What is built.** The gate of 725-3 also requires, for files of the architect's panel, that the session loaded `interface-design`
(measured first: whether the transcript path in the hook input shows the skill's launch; otherwise a marker written by a one-line
`npm run design-ready`). `check:steps` refuses a substep summary whose commits touched interface files without a line «Surfaces seen:»
naming `logs/eyes/*.png` files that exist (measured first: whether a summary's commit hashes are cheap to diff in prebuild; if not — the
line is required by the summary template and checked for presence).

**Done when.** The panel cannot be edited without the craft skill in the session, and «built» cannot be written without the screenshots.

**Proven by.** Plane 1 — samples: a panel file without the skill → refused, with → passes; a summary without «Surfaces seen» → red,
with real paths → green, with a path that does not exist → red (negative control). Plane 2 — 726-3's dashboard page is built through it.

**Rests on.** 725-3, 724-2. **Not in it.** Design reviews by a model (`review-page`, after the owner's yes with a price).
