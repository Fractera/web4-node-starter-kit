# 626-1 — Runtime: MiniLM-L12 on three systems

**What is built.** Nothing in a repository. A measurement in scratch runs `paraphrase-multilingual-MiniLM-L12-v2` in two runtimes:
(a) Node.js — `@huggingface/transformers` (onnxruntime-node underneath); (b) Python — fastembed (as measured on 2026-11-02, Python 3.11,
onnxruntime 1.19.2). On three systems: the owner's Intel Mac (i7-6820HQ, 16 GB), the owner's Windows computer, a Linux machine (a VPS or
a container). Per system and runtime: does it install, load time, one-text latency, a 100-text batch, RSS after load and at peak. The
vectors of 20 fixed texts (Russian and English) are saved per system and runtime.

**Done when.** The runtime is chosen in one line with its reason, and the element's memory price is known.

**How it is proven.**
1. The numbers table, per system and runtime.
2. Across systems and runtimes: the cosine between the vectors of the same text is ≥ 0.999 for all 20 texts. Negative control: two
   different texts of the 20 stay below 0.9 — the comparison is not trivially 1. (This is what lets 627 ship ready vectors.)

**Rests on.** Nothing.

**Not in it.** Another model (decided: MiniLM-L12). An Apple Silicon Mac, unless one is at hand — then named as not measured.
