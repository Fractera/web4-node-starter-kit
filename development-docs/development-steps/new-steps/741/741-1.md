# 741-1 — the edge: nginx forwards only the name it matched

**Done when:** on a server, no request with a name the server does not own reaches the core or an element, and every start of the core
on a server re-applies the generated nginx file.

## What is built
- `lib/hosting/nginx.mjs`
  - `proxy(port, upstream, name)`: `proxy_set_header Host` and `X-Forwarded-Host` take the block's own validated name (`row.host`,
    written as a literal — or `$server_name`, identical for a one-name block); `$host` disappears from every `proxy_set_header`.
  - The IP default block (port 80, `server_name _`), before the switch-on: `location = /api/health` proxied to the core with
    `Host $fractera_ip_host` — a `map $server_addr` that brackets IPv6 — so the core sees the IP it was reached at, never a client's
    name; `location /` returns the static card (D31 a): `default_type text/html; return 200 '<…>'`, built only from validated values
    (the zone from the table), in English and Russian, no `$` in the text; the ACME path stays. After the switch-on the 301 to the
    architect host stays as today.
  - A 443 default block whenever any certificate exists: nginx ≥ 1.19.4 → `listen 443 ssl default_server; ssl_reject_handshake on;
    return 444;`; older (Ubuntu 22.04, Debian 11: 1.18.0) → the first existing certificate of the table as its certificate and
    `return 444;` (the handshake succeeds with a public name, the request is dropped). New helper `rejectHandshake(version)` beside
    `http2Directive`, the same version parser.
  - IPv6 listeners mirror IPv4 exactly as today (`ipv6` flag).
- `scripts/serve.mjs`: after `start` and at the end of `rebuild`, when `nodePhase(root) === 'live'` (741-2 replaces the test by the
  place reader), run `node scripts/server.mjs nginx --write` and, only when the file changed, `sudo -n /usr/local/sbin/fractera-root
  nginx-apply`; a failure is printed with its reason and never stops the start (nginx keeps the last good file — `nginx -t` inside
  `nginx-apply`). This is how every server launched before 741 gets the edge fix: `node:update` merges, then runs the NEW
  `serve.mjs rebuild`.
- `lib/hosting/edge.mjs`: the comment names the third wall (the canonical name) beside the two existing ones.
- Tests in `scripts/hosting.test.mjs` (already in the prebuild chain).

## Proof — two planes, named in advance
1. **Unit (scripts/hosting.test.mjs):** for tables with 0, 1 and 3 names, with and without certificates, nginx versions 1.18.0, 1.22.1,
   1.24.0: no `proxy_set_header Host $host` or `X-Forwarded-Host $host` anywhere; each named block's Host is its own name; a 443
   `default_server` exists iff a certificate exists, with `ssl_reject_handshake on` only for ≥ 1.19.4; the IP block before the
   switch-on proxies ONLY `/api/health`; the card contains the zone and no `$`. **Negative control:** the same assertions run once
   against the generator of commit `82a074ed` (checked out into a scratch folder) and FAIL on the Host assertion — recorded in the summary.
2. **Live (the test server, after its `node:update` brings the core — never a hand edit):** `probes/host-forgery.sh 213.199.61.7`:
   every forged row → 000 or the card (no `owner@temporary`, no `visitor@showcase`); `TLS SNI nobody.invalid` → «handshake refused»;
   control rows: `https://aifa.dev/` (real name, real SNI) → 200 the site; `http://<IP>/api/health` → 200. **Negative control:** the
   before-numbers of `probes/README.md`. Plus `sudo nginx -T | grep -c 'proxy_set_header Host \$host'` on the server → 0 (read through
   the agent's SSH, no edit).
