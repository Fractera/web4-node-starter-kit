# 741-7 — the map of every behaviour that differs, and a guard that keeps it single

**Done when:** one document names every behaviour that differs between a computer and a server with its single reader and its proof,
and the build refuses a new place guess outside that reader.

## What is built
- `development-docs/reports/feature-where-the-node-lives-map.md`: one row per behaviour — what it does on a computer · on a server ·
  who decides (the record, the phase, the request's edge) · the proof of 741 or the step that owns it. Rows known now: the quick tunnel
  (741-4) · the edge and the names (741-1) · the owner at the keyboard (loopback + no edge mark; SSH window 741-5) · the temporary
  address trade (computer only, 741-3) · the showcase (configured site, 741-3) · the hosting page view, online bar, alarms, «open on
  this computer» (741-6) · the update path (`node:update` both; the fork sync is the computer's main agent's work) · the closed lid
  (computer: Cloudflare copies; server: nginx 503 page) · element birth (Cloudflare subdomain vs `name-up.mjs`) · certificates (server
  only, 742) · agent wakes in the phase `silent` (the phase, not the place) · the survival rule and memory (measured, same on both) ·
  Telegram bots (one poller per token — a server node needs its own bot; named, not built) · eyes and the Chrome extension (Chrome is
  the computer's; eyes run on both).
- `scripts/check-place-readers.mjs` + `package.json` `check:place-readers`, added to `prebuild`: fails when a file outside the allow-list
  (a) reads `server.json` for `phase`/`independent`, or (b) passes `window.location.hostname` to `isTemporaryHostname` /
  `isLoopbackHostname` to choose a VIEW. Allow-list with a reason per entry: `lib/hosting/{place.mjs,phase.cjs}`, the agent kits'
  `telegram.cjs` (phase `silent`), `owner-band` and `origin-notice` (they NAME the address), `access-gate` (its own lock).

## Proof — two planes, named in advance
1. **The guard on the tree:** green on the working copy after 741-1…6. **Negative control:** in a scratch copy, a planted component
   `if (isTemporaryHostname(window.location.hostname)) return <ServerLadder/>` → the guard fails naming the file and the rule.
2. **The map against the code:** every row's «who decides» cites a path; a grep for each path in the summary shows it exists (a row
   without a path is not a row).
