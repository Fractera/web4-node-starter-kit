# 741-2 — one record of where the node lives

**Done when:** every node answers «computer» or «server» from a record its own installation wrote, bound to its machine, and the
measurement only checks it — a disagreement is reported, never silently obeyed.

## What is built
- The record `data/node/place.json`, version 2 (D37): `{ "v": 2, "place": "home" | "server", "by": "launch" | "dedicated-server" |
  "migration", "at": ISO, "machine": "<sha256 of the machine id, first 16 hex>" }`. The words stay `home`/`server` — the indicator and
  `/api/node/place` already speak them. A file without `"v": 2` (the retired declaration of 276-3, e.g. this Mac's «server» of
  2026-11-13 10:15) is treated as absent.
- The machine id, read without a model and never stored raw: Linux `/etc/machine-id`; macOS `ioreg -rd1 -c IOPlatformExpertDevice` →
  `IOPlatformUUID`; Windows `reg query HKLM\SOFTWARE\Microsoft\Cryptography /v MachineGuid`. Unreadable → `null` (the check is skipped
  and said).
- Writer `scripts/place-record.mjs` (`--home | --server | --migrate`, `--root <folder>`): writes atomically (tmp + rename); `--migrate`
  writes only when no version-2 record exists: `server.json` with phase `live`/`silent` → server, else the measurement → `by:
  "migration"`.
- Callers of the writer: `scripts/launch.mjs` (the first start on a person's computer, before the stamp `started`) → `--home`;
  `scripts/dedicated-server/install.sh` `stage marks` (the FIRST stage on a server, before the build) → `--server`; `scripts/serve.mjs
  start` → `--migrate` (every installed node gets its record on its next start; nothing else changes).
- The reader `lib/hosting/place.mjs` `nodePlace(root, probe)` becomes: record v2 → if its `machine` differs from this machine's →
  `{ kind: measured, source: "measured", foreign: true }`; else `{ kind: record.place, source: record.by === "migration" ? "migrated" :
  "installed", mismatch: <measurement disagrees> }`; no record → the measurement as today (`source: "measured"`). Cached per process
  by the file's mtime (one `statSync` per call).
- `lib/node-state/place.ts` and `app/api/node/place/route.ts` pass `foreign` and `mismatch` through; the indicator
  (`components/node-state/node-place.client.tsx`) shows one line when either is true, with the reason (texts through its i18n file).

## Proof — two planes, named in advance
1. **Unit (`scripts/hosting.test.mjs`, a new block «place record»):** probe machines darwin / win32 / linux-public / linux-private ×
   record home / server / v1 declaration / none / foreign machine — the table of expected `{kind, source, foreign, mismatch}`; the
   writer's `--migrate` never overwrites a version-2 record. **Negative control:** a v1 file `{"place":"server"}` on a darwin probe →
   `home`, `source: "measured"` (today's lie is not obeyed).
2. **Live (two machines):** this Mac after the node update: `GET /api/node/place` → `home`, `migrated`, no mismatch, and
   `data/node/place.json` now has `"v": 2` (the 2026-11-13 declaration replaced); the test server after its update → `server`,
   `migrated` (it was launched before 741) — and a server launched after 741 → `installed`. **Negative:** copy the Mac's record into a
   scratch node folder with a forged `machine` → `foreign: true` from `node -e` on the reader.
