# 728-2 — the measure counts every byte; the letter goes only into the new conversation

**What is built.** In the kit master: `session.cjs` counts every byte the screen ever printed (`seen`) beside the 256 KB buffer;
`bridge.cjs` `whenIdle` and `pasteWhenReady` measure «quiet» by it; the clear branch of `sessionCommand` pastes the letter only after the
clear happened — the pulse `session-end reason=clear` written after `/clear` was typed, or a transcript born after it — instead of a fixed
5 s pause. Then `npm run agent-kit:update` brings the master into every copy.

**Done when** `npm run test:reset-wake` is green for the main agent and the element, and `check:agent-kits` says every copy is legal.

**Proof.** The tree: the test green (verbatim) and the same test red with the fix taken out (`git stash` — the negative control).
The wire/data, live after the node update: the main agent's own `session clear --continue` — the core log shows `/clear` after the
turn's end (`pulse turn-end`) and «пробуждён письмом» after «после сброса — разговор … записан»; the pulse shows the letter's
`turn-start` with the NEW conversation id.

**Rests on** 728-1.

**Not in it:** the window line (728-3).
