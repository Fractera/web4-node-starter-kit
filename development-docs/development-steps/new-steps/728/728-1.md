# 728-1 — the test that reproduces the 18:21 incident

**What is built.** `scripts/reset-wake.test.mjs`, `npm run test:reset-wake`. A fake Claude Code stands in for the terminal and the real
bridge copies drive it: `architect/build/_agent-kit` for the main agent (`build`), `architect/[item]/_agent-kit` for an element. The
fake prints a spinner while a turn runs, keeps its screen buffer full (256 KB — a long session), queues what is typed during a turn the
way Claude Code does (a slash command waits for the turn's end, words go into the running turn), and on `/clear` writes the pulse's
`session-end reason=clear`, starts a new conversation and writes its transcript where `resume.journalDir` looks. It all runs in a
temporary root (a link to `lib/`, its own `data/`) and a temporary home.

Scenarios: (A) the reset is asked while the turn goes on for 20 s more — the main agent and an element; (B) the reset is asked after the
turn ended (the quick path); (C) `/clear` never takes effect — the letter must not be pasted into the old conversation; (D) the measure
itself: a full buffer, more output — the measure moves.

**Done when** the test runs in about 40 s and is red on the current code in A, C and D, green in B.

**Proof.** The tree: the test's verbatim output on the current code (red). The negative control is the scenario B, which passes on both
codes (the test does not fail on everything).

**Rests on** the bridge's `sessionCommand` export and the global session map (`session.register`).

**Not in it:** a real `claude`, a model, Telegram.
