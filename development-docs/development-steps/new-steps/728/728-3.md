# 728-3 — the window line knows its conversation

**What is built.** `lib/agent-kit/limits.cjs` writes the status line's `session_id` into `data/services/<id>/context.json` (`session`)
and rewrites the record when the conversation changes, not only the percentage; `lib/agent-kit/window.cjs` reads the hook's `session_id`
and keeps silent when the record belongs to another conversation. A record without `session` (written before this step) is read as before.

**Done when** a fresh conversation's first window line is silent while the old conversation's record says 65 %, and the same conversation
still gets its line.

**Proof.** The tree: the scenario E of `npm run test:reset-wake` (the same record, two conversations — silent for the other one, the
line for its own; negative control: the same conversation must still get the line). The data, live after the node update:
`context.json` carries `session` equal to the running conversation's id.

**Rests on** 700-1 (the window line).

**Not in it:** the status line's text for the person.
