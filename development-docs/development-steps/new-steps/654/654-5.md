# 654-5 — the memory door: the space is the caller's key, not its word (memory element, core)

**Repositories:** `Fractera/fractera-memory-starter` `main` (the same release as 654-4's memory part); `Fractera/web4-node-starter-kit`
(`scripts/node-commands.mjs`). Delivered with 654-4 in one `node:update`.

## What is built

- `lib/memory/door.mjs` `authKind`: `X-Data-Secret` = the node (the main agent: `build`, `core`, any space — as in 650); `X-Element-Key`
  (the memory's copy of the key, the same test vector) = that element; **`X-Node-Key` no longer opens the memory** (custom elements hold
  it until 655 — with it they could name any `from`, the hole 650-main D4 left open).
- `callerOf` with an element key: the space IS the key's id. `from` (a body, a form) and `?source=` (GET, DELETE) may be left out — then
  they are the key's id; naming another element, `build` or `core` → 403 `space-not-yours`. Every verb (remember, recall, feedback,
  journal, forget, sources, signals, objects and their files) keeps 650's spaces; only who decides the space changes.
- The contract's version goes up (the lock changed for callers); `contract.mjs` names `X-Data-Secret` and `X-Element-Key`.
- **The core:** `scripts/node-commands.mjs` (`npm run remember`, `remind`, the object file) calls the memory with `X-Data-Secret`.
- README of memory: «Spaces» gets «Who you are is your key».

## Done when

An element's key keeps and finds only in its own space whatever `from` it writes, and the shared node key opens the memory no more.

## How it is proven (named in advance)

1. **Doors on the owner's node** (memory on, proof script, keys never printed): with B = `blocks`'s key and no `from`: «Запомни: у Бориса
   жёлтый велосипед, проверка 654» → 200, kept in space `blocks`; recall with that key → found; **with root's key → «Этого я не знаю»
   (negative control)**; with blocks' key and `from: ["root"]` → 403 `space-not-yours`; `X-Node-Key` → 401; the main agent's `npm run
   remember -- "проверка 654: ключ ядра"` and `npm run remind -- "Что у Бориса?"` → kept and found (the main agent sees blocks' space).
2. **The rows directly** (data with the master key): the phrase's row has `space = 'blocks'`; `memory-said--blocks` holds it,
   `memory-said--root` does not. The proof forgets blocks' space after (`DELETE /v1/journal` with blocks' key) and the main agent's proof
   phrase (space `node`). Lab: unit checks of `authKind` / `callerOf` (no header, a swapped id, `from` of another, `build` from an element
   key), prebuild 0, `tsc` 0, `next build` 0; CI three-os green.
