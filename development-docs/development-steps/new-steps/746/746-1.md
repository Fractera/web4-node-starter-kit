# 746-1 — the remover script

**Built:** `scripts/node-remove.mjs` (bare node, no `@/`):
- `--preview` (default): JSON — the folder, its name, the place (`placeKind`), the node's pm2 processes, the born elements with
  `deletionRisk`-like counts (commits, unpushed or never exported), the journals in `~/.claude/projects/` that belong to the folder,
  what stays (fork, servers, Cloudflare, subscription, cloudflared, pm2).
- `--yes --confirm <folder name>`: refuses on a server or a wrong name; else copies itself to `os.tmpdir()` and starts the copy with
  `--stage <root>` through `scripts/spawn-free.mjs`; the stage waits 3 s, runs `serve.mjs remove --yes`, deletes the journals, deletes the
  folder (`rm` recursive with retries), writes `~/Fractera-removed-<date>.txt`.
- `FRACTERA_REMOVE_HOME` (tests): the home folder for the journals and the report.

**Done:** a scratch node folder is gone with its journal and the report exists; a wrong name changes nothing.

**Proofs:** (1) `scripts/node-remove.test.mjs` on a scratch folder in tmpdir — the real removal, the negative control (wrong name, a
server place record → refused, folder intact); (2) the preview on THIS node read by eye (the folder, the elements, the journals).

**Tasks this needs:** none of interface. **Parts born here:** none.
