# 670-1 — The gatekeeper wakes an asleep element on an i2i call — proven on the owner's node

## What is built
Nothing — a live verification of 663-4 on the owner's node (macOS, his Mac). A defect found becomes its own substep (route A), never a
quiet fix inside this one.

## What counts as done
An `auto` + `wakeOnCall` element put to sleep by the load rule answers a call on its own port after its cold start; an element turned off
by a person (not by the rule) is not woken; the cold start and the refusal window are measured and written to «measured».

## How it is proven — two planes, one negative control
1. **The wire.** `npm run power -- blocks off --by-rule "670-1 gatekeeper proof"`, then
   `curl -s -o /dev/null -w '%{http_code} %{time_total}' http://127.0.0.1:<blocks port>/health` → `200` and the cold start in seconds.
   A second call fired ~1 s after the first, while the element rises → its result recorded (held or refused — the window named in
   `element-power`).
2. **The process and the registry.** `npm run power -- blocks status` before the call (off, by the rule) and after (on); `npm run
   serve:status` shows blocks online; the gatekeeper's log has its line for blocks.
   **Negative control:** the same call to stripe's port (off by the person's default, `switch: manual`, no `wakeOnCall`) → connection
   refused, `npm run power -- stripe status` still off.
Ports are read from `logs/runtime.json` / `serve:status`, never remembered.

## Rests on
663-3 (the rule's flag `--by-rule`), 663-4 (the gatekeeper `scripts/gatekeeper.mjs`), the passport `power` of blocks (`auto`,
`wakeOnCall: true` — `npm run load` shows «сам+вызов»).

## Why blocks
The registry of page blocks is read by element agents while they build; no agent builds now, nobody loses anything for the seconds it
sleeps. `design` and `config` would repaint or re-read every element; `memory`, `graph`, `vectors`, `embeddings` serve searches.

## Not in it
The agent layer (670-2); any change to the gatekeeper; a2a (670-6); queueing calls during the cold start.
