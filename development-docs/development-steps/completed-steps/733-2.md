## What was built

- A tool's card carries `title` (en, ru), `version` (x.y.z) and `parts: [{ id, version }]` — the tools it is made of (the owner: «Да,
  рецепт со ссылками»). In `_tools/<id>/tool.json` (`scripts/build-tools-map.mjs` refuses a card without them) and for a tool carded in a
  folder's `parts.json` (`lib/parts/parts-map.mjs`, kind `tool`).

  `parts`, at the versions those tools have now. Three troubles, three words: used and not named, named and not used, held at an old version.

  the table with search and pages, the four design editors, the node wallet, the build log, the element's document, deals, preview,
  environment, passport, product quiz, remote settings, reverse engineering, the Tools tab and its look. Not tools (26): display without an
  action (the state dot, the rating, the alarm band, notices, images), layouts, providers, section islands, the vendored AI Elements
  family. My rule, for the owner's review: a tool does something for a person or lets them do it; showing alone is not a task.
- The measured tree, written into the cards: the voice textarea and the voice line are made of the voice control, the voice control of the
  voice input tool; the Tools tab of the voice textarea, the terminal drawer and the look; the look of the window, the chat and the code view;
  the paste window of the window and the voice control; the product quiz of the block task and the terminal.
- `parts_find` names a tool in both languages with its version and «Made of: …» (it printed `[object Object]` once the title became
  { en, ru } — found by running it, fixed).
- The words guard: «Block task» (a task for a page block — the address of a container) now sits in the map as `"en": "Block task"`;
  its allowed form was added beside `"title": "Block task"`.
