## Mistakes
- My rollout script compared the clocks of storage, vectors and graph with data's clock AFTER it had rewritten data's: their
  `due.ts`/`runner.ts` stayed old in v1.1.18 / v1.2.1 / v1.2.1 and came as a second patch (v1.1.19, v1.2.2, v1.2.2). Lesson: a
  reference read inside a loop that changes it is a moving reference — read it before the loop.
- I quoted the owner as «через агента оркестра»; his words were «через Гента оркестра» (speech to text). The skills now retell it
  without quotes and quote only verbatim phrases.
- The auto-mode classifier refused writing the push token into `data/node/github/.env` (credential materialization): the template
  tool could not push; releases and rollouts went by plain `git push` with git's own credentials (`rollout-636.mjs` in scratch).
- The stripe clone's `origin` was a local scratch repository: its first push went nowhere useful; pushed to GitHub by URL.

## Limits
- A reminder fires only while the computer and the memory are on at its minute (the memory is on while more than 1 GB is free, step
  601); a missed run is not made up, the calendar shows it.
- Each alarm wakes the memory's build session (Opus by its launch model) and then the main agent — the subscription pays twice.
- A clock that cannot wake its agent (free memory below a session) writes the failure into its run log; no retry (465).
- data, storage, vectors and graph keep their own `CRON.json` (backup); `agent-task` was added to their catalogs, their «why» kept.
