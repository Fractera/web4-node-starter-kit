## What was done
- Measured before: the panel's «+ Создать элемент» made a draft with only a random id (`createDraft`, 314-1), its birth passed no
  `--name` (`birthArgs`: `--look`, `--repo`), and `item-birth.mjs` wrote `props.name = id` — such an element was called by its id in the
  menu, the header, the title and the dialogs. The custom template itself prints no id (`ownId()` only builds links to the core).
- `create-draft-button.client.tsx` — the click opens `AppDialog` «Новый элемент» / «Новый нативный элемент» with one field «Название»
  (60 characters, autofocus; «Создать» disabled while empty; Enter submits); created → a full navigation to its page (the soft
  `router.refresh()` of the menu was measured unreliable in 678). The raw `<button>` became `Button` — the file left the shadcn debt.
- `_lib/draft-menu.tsx` — the window's words and `appDialogUi(lang)` passed by value from the server.
- `app/api/architect/drafts/route.ts` POST — `{ name, native? }`, `name-file.cjs` `cleanName` (now exported), empty → 400
  `name-required`; `createDraft(native, name)` writes it with `writeName` (the one name store, 678-1).
- `app/api/architect/drafts/[id]/route.ts` DELETE — the draft's name file removed with it (`writeName(id, "")`).
- `lib/web4-items/birth-args.mjs` — `birthArgs(id, plan, name)`, pure; `birth.ts` `startBirth` passes `ownName(id)`, so the passport of
  an element born from the panel carries the person's name.
- Words: `web4-drafts.i18n.ts` (`createTitle`, `createNativeTitle`, `createText`, `nameLabel`, `createConfirm`; en, ru).
- `scripts/draft-name.test.mjs` (7) in the prebuild, `npm run test:draft-name`; `lib/parts/PARTS.json` rebuilt.

## Proof
1. Over a temp folder (`draft-name`, 7 green, inside the chain 83/83): **negative** — `cleanName` gives '' for nothing, spaces, a number,
   an object, an array (the door's 400); a name is folded and cut to 60; written → `ownName`/`displayName` give it; removed → the name file
   is gone and the address answers again; `birthArgs` carries `--name` for a custom element (with and without a repository) and a native
   one, and **negative** — no name, a blank name or `null` add nothing.
2. Live on aifa.dev in his Chrome (14:12–14:16 UTC): «+ Создать элемент» → «Новый элемент», the field focused, «Создать» disabled while
   empty; «Проба имени» + Enter → `/ru/rq2in`, the tab «Проба имени | Fractera», the heading «Проба имени», the menu «ПРОБА ИМЕНИ», the badge
   «Черновик»; deleted by its name → `/ru`, the menu without it, `GET /api/architect/drafts` → `[]`. **Negative on the live door:**
   `POST /api/architect/drafts` with `{}` and with `{ "name": "   " }` → `400 {"ok":false,"reason":"name-required"}` both, drafts still `[]`.
