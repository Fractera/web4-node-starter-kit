  «behind N» against Fractera's main as the node user and keeps its answer in `/root/.fractera/probe.json`. `state.sh` reads the server's

  signin · clear). Islands `components/hosting/server-place|server-launch|server-launch-check|server-launch-domain|server-launch-end.client.tsx`:
  an empty form on every visit, then seven steps; a server node (or its bare IP) shows its own 737-19 ladder.
- **738-5 domain and certificates.** The domain chosen on the page lives on the server (`/root/.fractera/domain.json`) with detection, who
  writes the records, the records of a fresh node (`@`, `www`, `architect`, `auth`, `*`) and a first check from public resolvers; once the

  certificate · HTTPS; an own certificate can still be uploaded (relayed by stdin).
