## What was done
- `scripts/catalog/build.mjs`: 3,240 useful cards (`use` ≠ skip, no risks) → 17,145 pieces (the card's summary; each task) → vectors by
  the node's `embeddings` (MiniLM-L12-v2, 384, normalized) in 811 s → `vectors.f32` (26.3 MB), `rows.json` ([mark, piece]),
  `manifest.json` (model, dims, rows, cards, skip, cardsSha, vectorsSha); `pack` → tar.gz; `release` → `gh release create`, the asset's
  size checked, `release.json` written.
- `lib/agent-kit/skills/catalog-index.mjs`: `loadIndex`, `embedTexts`, `searchIndex` (a card's score is its best piece; threshold 0.60).
- `scripts/catalog/threshold.mjs` + `fixtures/threshold-30.json`: 20 questions with a right card known in advance, 10 outside.
- `lib/agent-kit/skills/catalog/skip.json`: the 2,090 skip-cards as a short list (id, reason, risks).
- `scripts/catalog/store.mjs`: the folders of the useful skills whose licence allows a copy (MIT, MIT-0, Apache-2.0, BSD-2/3, ISC, 0BSD,
  Unlicense, CC0-1.0), file for file, each folder's fingerprint checked against its card; beside each source its own LICENSE / NOTICE
  (taken from the repository's root at the fetched commit) and SOURCE.md; one `manifest.json` with the git blob of every file.

## Mistakes
- I built the catalog first as a LightRAG space on the owner's node (22:56–23:38, 60,292 vectors, 246 MB). Measured after: ~11 s and
  up to 1.36 GB a query — the graph element starts Python for every call and loads all its JSON (the owner's mode of 2026-10-22); the
  relationship and topic vectors gave leaks at every threshold up to 0.55 in the mixed mode. The measure that should have come first:
  the pieces alone (naive) — 19/20 and 0/10 at 0.60. Three quarters of that build is unused; the space waits on the node for the
  owner's word to remove it.
- I told the owner «~100 MB» for the package before measuring; the graph would have been ~150 MB, the file is 24.5 MB.
- My first answer about «the graph is being built» did not say that the cards are text and the vectors a second layer — the owner
  asked twice what was rebuilt and whether past work was lost.
- `gh release create` was refused by the auto-mode classifier (a public surface); the owner ran it and then allowed `gh release`.
