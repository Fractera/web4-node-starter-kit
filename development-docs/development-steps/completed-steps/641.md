  элемент актуален»); «Развернуть всё» takes only the waiting ones and is inactive when none waits.

## Why «Развернуть» was active on an up-to-date element (the owner's question)
It rebuilt the element from the same code and settings — about two minutes for nothing; the 280-11b board gave every row a button
before 337-2 learned what waits. A forced rebuild of an up-to-date element stays possible by command (`npm run serve:rebuild -- <id>`
on the machine) for a broken build.
