# 670-8 — No call lost during a cold start: the caller waits — decided; its code belongs to the elements (671)

**Repository:** Fractera/web4-node-starter-kit — the commit of this summary; no code in the core.

## Decision (mine — the owner, 2026-11-07: «your choose in the all process»)
**Way 1, the caller waits:** a refused connection to an element asleep by the load rule (`off.byRule` + `power.wakeOnCall`) is retried
with a short backoff up to the cold-start limit; a person-turned-off element fails fast. **Way 2** (the gatekeeper as a permanent proxy)
rejected: every call of sleeping-capable elements would pass one more hop forever, and the gatekeeper would become their single point
of failure — against the instruction («there is no single point of failure»).

## Where the caller is — read, not assumed
Every place in the core that calls an element's port (`git grep "127.0.0.1:${" / "localhost:${"` over `lib` and `scripts`, read
2026-11-07): health checks (`health-watch`, `element-power`, `gatekeeper`, `deploy-elements`, `element-preview`, `element-move`), the
Dashboard's probes (`dashboard-rows.ts`), the settings signals (`catalog-push.ts` — already skips every element that is off, asleep
included: `.filter((s) => … && !power.offOf(s))`), the architect's pages through `lib/microservices/*`, and the deep memory, which
`npm run remember` / `remind` turn on themselves before calling (skill `element-power`). **No i2i door call goes from the core:** a
neighbour's door is called by the ELEMENT's code — the custom and native templates. So the retry lives in the elements' i2i client
→ `new-steps/671-templates-carry-the-order-chain-to-every-element.md`, item 3. An outside (a2a) caller never meets the window: its
order is answered at once with an A2A Task (plan 672).

## Proof
1. The measurement that started it (670-1): call 2, 1 s into blocks' 2.9 s cold start → `ECONNREFUSED after 0.00s`.
2. The reading above, with the one line that shows the core's signals never knock on a sleeping element:
   `lib/web4-items/catalog-push.ts:53  .filter((s) => typeof s.port === "number" && !power.offOf(s))`.
