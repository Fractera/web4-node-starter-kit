## What was done

- `lib/openai-error.cjs` reads a refusal by HTTP status AND `error.code`/`type`. The list comes from OpenAI's error-codes guide
  (https://developers.openai.com/api/docs/guides/error-codes, read 2026-11-12, not from memory): `no-funds` (credit_balance_exhausted,
  insufficient_quota), `spend-limit` (organization_/project_spend_limit_exceeded), `usage-limit` (organization_usage_limit_exceeded),
  `rate-limit` (incl. slow_down), `overloaded` (503, server_is_overloaded), `server`, `bad-key`, `ip-blocked`, `region`, `forbidden`,
  `not-found`, `bad-request`, `timeout`, `unreachable`. Codes the guide does not name (model_not_found, context length) are read by
  status only, as the SDK's classes do. Each reason has OpenAI's own page to act on (billing, limits, keys, the IP allowlist, status)
  and says whether retrying can help («retrying billing, spend, or quota errors won't restore API access» — the guide). OpenAI's
  message goes to the node's log with `org-`, `proj_` and `sk-` fragments hidden.
- All 20 direct callers use it: the voice tool and `/api/transcribe`, `/api/i18n/translate` and the translations dialog, fact-draft,
  socials-ai, `/api/openai-models`, the key probe of `/api/architect/environment`, `lib/a2a/translate.ts`, and the agent kit's
  `translate.cjs`. The kit carries a byte-identical copy `core/server/openai-error.cjs` because it lives without the core; the 12
  group copies were updated (two by the installer; ten native groups by copying the two changed master files and the version line,
  since the installer wants `WEB4-ITEMS/core/<id>`, which the working copy does not have and the settings forbid touching).
- The person's words: one dictionary `lib/i18n/openai-error.i18n.{ts,json}` (en, ru; in `check:i18n` and `i18n:export`). They are
  chosen on the server (doors take `uiLang`; the tools already had `lang`), and the screens show `words` plus a link «Открыть в OpenAI».
- The guard `check:openai-calls` (in prebuild): a direct call to api.openai.com without the reader, a drifted kit copy, or a code of
  the guide read wrong is red. The test `npm run test:openai-errors`.
- The touched voice field and translations dialog moved `title=` to shadcn `Tooltip` (the law of 730).
