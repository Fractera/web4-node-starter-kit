**Commit:** template `Fractera/fractera-custom-item-starter` — `069311a`. No tag: the release is 717-7. Plan: `new-steps/717/717-3.md`.

## What was done and how

- **A prototype's own set** — `prototypes/_pages/<id>/sections/`, the shape of `components/sections/` (`index.ts`; one folder per section
  with `index.tsx`, `markdown.ts`, `README.md`). `npm run prototype -- new` writes its empty `index.ts`; `done` refuses an incomplete set,
  a repeated kind of the element and a kind the page names that neither set has. The prototype's page draws the element's set and its
  own: the generated `prototypes/_components/prototype-sections.ts` (written by `npm run prototype` and by `node scripts/prototype.mjs
  index` in `prebuild`, never by hand) feeds `childRoute` → `createContentPage` → `StandardContentPage` → `PostBody` (one optional
  `moreSections`; `kindsOf` in `page-body.tsx` turns a set into what the factory draws).
- **The pin** checks first and moves nothing on a refusal — the winner's set complete, no kind of the element repeated, the losers'
  sections committed (`git status`, paths literal). Then the winner's folders move into `components/sections/` with their import and set
  line (`addToSet`); the losers' leave the tree, their records name them and the commit (`sections`, `sectionsAt`); every prototype goes
  to `_archive/` with record, tokens, `DESIGN.md`, words and shots — no code; the wiring is rewritten; the sections the source page named
  before and no page names now are listed for the agent (nothing deleted for it).
- **`check:sections`** (`scripts/check-sections.mjs`, in `prebuild` before `check:page-sequence`): each set both ways — a folder without
  its import and line, a line without its folder or importing another folder, a folder without its three files — for the element and
  for every prototype; a prototype's kind repeating the element's; the wiring stale. One reader for all: `scripts/sections-lib.mjs`
  (`readSet`, `setFolders`, `setProblems`, `addToSet`, `repeatedKinds`, `pageFolders`, `kindsOfPage`).
- **The archive is history:** `check:page-sequence` skips `_archive/` and lets a prototype's page name its own set; the migration's map
  skips `_archive/` (`check:words` reads no history); `stamp-widget-ids` covers a prototype's own sections.
- **The words:** the design pass (`.claude/modes/build-design.md` — the order step 5 and the pin), the READMEs of `components/sections/`,
  `prototypes/`, `_pages/`, `_components/`, `components/sections/index.ts`, `lib/prototypes.ts`, skill `use-page-tree`; tree manifest
  (522 paths).
