## Found on the way

- `npx shadcn@latest add table` with this `components.json` wrote `import { cn } from "cn"` and installed an unrelated npm package
  `cn` into package.json. Reverted; the import points at `@/lib/utils`. Whoever adds the next shadcn part must check both.
- Proposal for the owner: Exa shows as an «example» at «Главный сайт» and «Клип» — the sample SUBSCRIPTIONS.json of the template.
  A real service an element connects should set `"example": false`, otherwise the passport reader treats it as an example (its default
  is `example !== false`). Worth a line in the element skill `connect-external-service` (726-2, the templates).
