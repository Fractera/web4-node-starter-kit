**What and how.**
- **The key** — `lib/data-store/element-key.mjs` (word for word in data, storage, vectors): `<id>.<mac>`, the mac an HMAC-SHA256 of the
  node's `DATA_SECRET` over `fractera-element-key:v1:<id>`; the id must be a registry id (`[a-z0-9-]`, ≤ 63, no dot). The shared lock
  `auth.mjs` checks the header `X-Element-Key` FIRST — before the no-auth mode and the node key — so a presented key is always checked,
  a bad one is 401 `bad_element_key`, never «the node», and a request with both keys gets the element's view (`req.element`,
  `req.authVia = 'element'`). `elementMayUse(isOpen)` — each store passes its own rule of the doors an element key may reach: data — the
  `/db/*` doors, `/db/whoami`, `/capabilities`; storage and vectors — none yet (403 `not-for-an-element` until 654-2 / 654-3).
- **The element's own database** — `db.mjs` `dbOf`: an element key works on `data/elements/<id>.db` (opened once per process, WAL,
  foreign keys on, created at its first call); the node key on the node's `data.db`, and with `?space=<id>` on an EXISTING element
  database (404 `no-such-space` otherwise — the node's call never creates one). An element's SQL with `ATTACH`, `DETACH`, `VACUUM INTO`
  or `load_extension` (strings and comments stripped first) → 400 `outside-own-database`. `POST /db/claim { element, tables }` (node key
  only) copies schema, indexes and rows of the node's tables into an element's database (a table already there — 409). `GET /db/whoami`.
- `scripts/check-element-key.mjs` in each `prebuild` — the key's test vector (`root` under `fractera-test-secret` →
  `root.J4UAgJ_XnToPRyXPKaG5TB69cVHfiWh8FomI5RRQNHI`) and 8 bad forms refused; the same vector goes into the graph, the memory and the
  core's installer later in 654.
- README of data «Whose tables», a line in the storage and vectors README, data's `CLAUDE.md` §11 «Whose tables».
- **A defect of the lock fixed on the way:** `isSchemaRoute` compared the path case-sensitively while the router matches segments
  without case — `POST /DB/migrate` reached the arbitrary-SQL handler as the data class, open to a privileged session cookie; the path is
  lower-cased now (and the element doors match without case, like the router).
