## What was done
Three sections, English, through `humanizer` (no dashes added):
- **«What a node and an element are»**, right under the badges — the node: one computer or server with the core and its elements;
  the element: a microservice and a server of its own (folder, repository, port, process, agent, address), any number of pages or
  none (CLAUDE.md §3).
- **«Launch your own server whenever you want»** — «Domain and hosting» → «A dedicated server», the IP and the root password, seven
  steps without a model; domains, subdomains and certificates handled by the node, a renamed or deleted element's name follows it or
  goes away (750); the computer is never stopped; a second or a tenth server the same way; each server a fresh node with its own keys
  and accounts.
- **«Updates and rollbacks»** — the banner's two moves (sync the fork — the main agent can — then «Update the core build» → the
  Deployments tab); a failed core build brings the previous version back; an element's «Roll back to a version» — any earlier
  version, a new commit, no downtime; the database is not rolled back.
