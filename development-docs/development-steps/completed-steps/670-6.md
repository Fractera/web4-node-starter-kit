## The finding that answers the owner's first question
Skill `provider-rules` (the node's own reading of Anthropic's terms) lists «other people's work on the owner's subscription» among what
breaks them. So an outside paid order must never be served by a Claude Code session on the owner's subscription: the thing an order
wakes is the element's PROCESS and its DOOR; the Claude agent builds the capability (the owner's own work) and hears about an order it
cannot serve only through the main agent. Inside the node (i2i) the worker session on the owner's subscription is the owner's own work.
