# 726-1 — the ledger of paid calls: every call of the core to OpenAI writes one line, `npm run money` reads it

Closed 2026-11-12 in the autonomous night run. Repository: Fractera/web4-node-starter-kit — `bdced7ea`. Live on the node: update
`7b4cc6e7`. CI of `bdced7ea`: success (windows-latest and ubuntu-latest, run 43113799088).

## What was done

- `lib/usage-ledger.cjs` appends one JSON line per paid call to `data/node/usage/<YYYY-MM-DD>.jsonl` (UTC, outside git):
  `at, who, provider, endpoint, model, status, ok, reason, code, message, tokensIn, tokensOut, ms`. A line is built from that closed
  list only, so a prompt, a key or a person's words handed to it are dropped. A write never throws: a full disk loses a line, never the
  answer. Tokens are read from every shape the node meets: chat `prompt_tokens`, transcription and Responses `input_tokens`, the AI
  SDK's `inputTokens`.
- All 21 callers write their line: the 20 `fetch` callers of 726-0, plus the menu's AI search `app/api/architect/menu/ai`. That one
  calls OpenAI through the AI SDK with no literal host, so the first guard could not see it. The reader learned the SDK's error shape:
  `readOpenAiSdkError`, AI_RetryError → `lastError` → AI_APICallError `statusCode`/`responseBody`, read from
  `node_modules/ai/docs/07-reference/05-ai-sdk-errors`. Its usage comes from `totalUsage`.
- The kit carries a byte-identical copy `core/server/usage-ledger.cjs`; all 12 group copies are updated (`check:agent-kits` green).
- `npm run money` shows today by consumer and provider: calls, answered, refused with reason and OpenAI's code, tokens, and the last
  refusal's message. Flags: `--day`, `--who`, `--days`, `--json`.
- `check:openai-calls` requires the ledger as well as the reader, and also treats a file that imports `@ai-sdk/openai` as a caller.
- My decision (autonomous run, reversible): the ledger counts only paid calls (OpenAI today). Free calls (Telegram polling, GitHub,
  Cloudflare) would bury the paid lines. A new paid provider joins by calling `record` with its own name.

## Mistakes

- My edit helper `open(p,'w').write(f(s))` truncates the file BEFORE `f` runs. When an edit's anchor did not match, it left
  `app/api/architect/menu/ai/route.ts` empty; restored from git (it had no edits of mine yet). From then on the helper writes only
  after the new text is built.
- I cut the kit fingerprint out of the guard's line with `cut -c`, and the multibyte «≠» shifted it by two characters; all 12
  manifests got a wrong version until the guard said so.
- TypeScript reads the destructured parameters of a `.cjs` as required. `tsc` refused the calls without `model`/`usage`; fixed with
  JSDoc types.
