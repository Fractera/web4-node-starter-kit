# 624 — First launch on a Mac: real available memory, the Telegram app requirement, quick links (closed 2026-11-02)

## The owner, verbatim
«мой компьютер сейчас имеет память 16 ГБ … до этого я работал на Windows компьютер у него было восемь но даже на нём я никогда не
получал такие ограничения»; «мы нигде ранее в документации не писали о том что пользователь должен установить Telegram»; «внутри
вкладки активации подписки должны быть быстрые кнопки для перехода в терминал и для перехода в Telegram»; «внутри такого чата с
информации о ошибке не хватает памяти предложить … закрыть … используемое приложение»; «что если бы ты мне сказал после завершения
установки что всё успешно запущено и для экономии памяти рекомендуется выключить этот чат установки»; then «go».

## What was wrong
Telegram answered «Агент build не включён: мало свободной памяти (свободно 114 МБ, нужно 300 МБ)» on a 16 GB Mac with 79% free
(`memory_pressure`). `os.freemem()` on macOS is only `Pages free` of `vm_stat`; macOS keeps that near zero and holds the rest as
inactive pages and file cache it gives back on demand. Windows and Linux already report available memory, so only Macs were hit —
every Mac, always. The same number fed the deep memory rule (on above 1 GB — never on a Mac), the closed-lid build log and «This
computer».

## What was done
- 624-1 `lib/free-memory.cjs`: `availableBytes`/`availableMb` — on macOS free + inactive + speculative from `vm_stat`, elsewhere
  `os.freemem()`. Used by the agent kit bridge (from the node root, like `modes.cjs`), `lib/deploy/quiet-build.cjs`,
  `scripts/memory-by-free.mjs`, `lib/web4-items/machine.ts`.
- 624-2 The refusal names what uses memory: `topApps(3)` (`ps`, `tasklist` on Windows; the node itself, system services and
  Telegram are never named), then the advice — close the Claude Code installation chat and spare browser tabs, press «Turn on»
  again; if it happens often — ask the main agent which computer or VPS to move to (law 6: a consultation, never a refusal).
- 624-4 Agent kit: under «Claude Code subscription» — «Open the terminal» and «Set up Telegram» (`core/agent-links.tsx`; the islands
  are already over 250 lines, so a separate server component); above the Telegram steps — «You need the Telegram app» with
  telegram.org/apps. A born element gets its own tree addresses (`build/terminal`, `build/telegram`). 12 copies updated.
- 624-3/624-5 README «How to install»: step 2 — install Telegram and sign in; step 7 — close the installation chat. The AI-agent
  section, step 7: recommend closing the chat, name the Telegram app. Launch welcome: item 3 no longer says «keep this chat open» —
  the main agent connects the domain; item 4 names the app; item 5 — close this chat, go on in the node's terminal or Telegram.

## Proof
1. On the owner's Mac with the node running: `os.freemem()` 78 MB, `availableMb()` 6615 MB; `memory-by-free --dry` — free 6599 MB,
   threshold 1024 → keep-on. `topApps` — Safari 2.2 GB, Claude Code 626 MB, Preview 227 MB. Both refusal texts rendered with those
   numbers (en, ru).
2. Guards of the build chain (except the machine-bound ones: check-local, ensure-env, check-origin) — all pass;
   `===AGENT_KITS_OK=== копий в порядке: 12, долгов: 0`; `tsc --noEmit` — no errors in the changed files (the one error is the
   generated previews file, absent in a clean clone).

## Limits
- The new pages and the Telegram refusal were not seen live: the owner reinstalls the node from the original to see them.
- The templates custom/native were not checked for their own `os.freemem()`: element code is not read from the core.
