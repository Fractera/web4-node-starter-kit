## What was done
- `catalog-index.mjs` `catalogFileText`: the answer tells the agent to show EVERY found skill (own first), one or two lines each: what it
  does and the one thing it especially likes, from the card (a method, a template, a check, a format), or plainly why it does not fit.
  Then the advice: the strongest one as it is, or the person's own skill assembled from the best parts of several (text copied only from
  a copyable licence, the rest as an idea in its own words), and an invitation to talk it over. Install only after the yes.
- `mcp.mjs`: `SKILLS_MCP_ROOT` names the node whose catalog is read, set only by a test run of new code over a live node's data.
- The Sonnet test bench (scratchpad `p646/`): the main agent's `CLAUDE.md`, soul and `.claude/skills` copied into an empty folder;
  `claude -p --model sonnet --strict-mcp-config --mcp-config <the new mcp.mjs over the owner's catalog> --setting-sources project
  --tools Read,Skill,Glob,Grep`; no plugins, no Telegram tool, no hooks, no diary, nothing reaches the owner. `judge.mjs` reads each
  stream: the skills_find calls, what came back, the answer.
