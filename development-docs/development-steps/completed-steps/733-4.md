## Defects found on the live plane (open)

- **An element searches by words only.** `meaning()` needs `lib/agent-kit/memory/embed.cjs` and the node's data key; an element has
  neither, and must never have the key — so in every element `parts_find` prints «the node's vectors did not answer», which is not
  true: they are unreachable by design. Proposal (733-10): the core answers the meaning half — a door `POST /api/node/tools/find` with
  `X-Element-Key`, the same `findParts` over the node's index with the core's vectors, the element's own map passed as cards; words stay
  the offline fallback, and the line says «words only — the core did not answer».
- **The core ranks a composite above the tool.** `npm run parts -- обрезать картинку` in the core: StaticImage 0.743 above Image
  cropping 0.728 — the meaning half lifts every «image» card; a tool whose words meet the verb should win. To weigh in 733-9.
