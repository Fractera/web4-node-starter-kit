## What was wrong
1. Root v3.0.13: the home cards are buttons with `h-full`; Safari on macOS resolved the 100 % against a box taller than the grid row,
   so the cards ran down over the panel below. Chrome on Windows — the owner's machine until now — did not.
2. The node code inside the suggested bot username was `sha256(node folder | hostname)` cut to 4 hex: the same folder on the same
   computer after a reinstall suggested the same username, and BotFather answered «Sorry, this username is already taken» (the bot
   stayed with the earlier Telegram account); 65,536 codes for everyone.
3. The main agent did not answer in Telegram: `telegram@claude-plugins-official` was not installed (`~/.claude/plugins/installed_plugins.json`
   had no entry) and nothing installed it — neither the launch nor the panel. `channelLaunch` returned `ok: false`, the bridge started
   the agent WITHOUT the channel, and the bot still wrote «Агент build включён и получил ваше сообщение».
4. The main agent's bot page lived only under «Main agent → Messenger → H2A».
5. `skills_find` searched only the node's base of 8 skills and only with an OpenAI key; the main agent answered a large product request
   with a ready plan instead of asking about an analog and the product quiz.

  `h-auto` (the grid's `items-stretch` keeps them equal).
- Core `e59204f`:
  - `architect/kits/_agent-kit/core/server/telegram.cjs` (+ the 12 copies by `agent-kit:update`): the node code is 5 random base36

    `claude plugin install telegram@claude-plugins-official` before the channel launch (and `claude plugin marketplace add
    anthropics/claude-plugins-official` when the catalog is missing); `runClaude` runs a Windows `claude.cmd` through the shell, the way
    of `scripts/ensure-claude.mjs`.
  - The menu group `architect/main-telegram` (order 19, right above «Main agent» 20, icon `send` added to
    `components/workspace/menu-icons.tsx`) — only a redirect to `/architect/build/telegram`.
  - Registry: root pinned to v3.0.14.
- Core `02d065b`: `lib/agent-kit/skills/catalog.mjs` — the open catalog skills.sh through the pinned CLI `skills@1.7.5` (telemetry off;
  the search API answers 401 without a Vercel OIDC token); `skills_find` (`lib/agent-kit/skills/mcp.mjs`) asks the node's base and the
