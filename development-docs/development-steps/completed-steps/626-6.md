## Where it lives
`Fractera/fractera-memory-starter` `d771469`, tag **`v2.2.9`**; the core pins it (the commit of this summary).

## What was done
- `lib/memory/node.mjs`: `vectorsOf`, `vectorOf`, `vectorModel` and the OpenAI embeddings call are gone; `embeddingsUsable()` asks the
  node's `embeddings` (`GET /api/embed-status`, the node key; `EMBEDDINGS_URL`, or the registry's port of `embeddings`) whether it
  counts. A model still loading (`idle`, `loading`) is usable — its vector calls wait for the load; a failed load, a refused key or no
  answer is not.
- `said-vector.mjs` (`memory-said`), `feedback-vector.mjs` (`memory-feedback`), `fractera/objects.ts` (cards of things): the memory
  sends `text` to store and `query` to search; the vector element counts both through `embeddings`. `objects.status().configured` is
  the vector element's own `configured` (no OpenAI key behind it any more); a refused card search stays `no-vector`.
- `verbs.mjs` `remember`: before the parsing call `think(EXTRACT, …)` one `embeddingsUsable()`. Not usable → no model call, the answer
  `toolFailure` (`tool-unavailable`, tool `vector`, stage «подсчёт векторов», the reason in `why`), the message keeps its row in
  `messages_that_came_into_memory` with status `failed`, the journal names the refusal. No queue, no timer.
- `.env.example` `EMBEDDINGS_URL` (derived — the installer's neighbour rule); README «Where a phrase goes» and the vector row;
  `CLAUDE.md` section 11 (the element's own).

## Limits
- The cards of things were not run on the stand: it has no storage element (`/media`), so `find` stops at `store-unreachable`. The
  same doors and fields as the phrases, type-checked by the build; the owner's node shows them live after 626-8.
- `NEAR_SAID`, `NEAR_FEEDBACK` (0.4) and `OBJECT_NEAR` (0.36) were measured on OpenAI's model and are kept; the scores above sit well
  inside them, and they are measured again on the live diary in 626-8 (a value is not tuned on the set it is proven on).
- The plan said «not `ready` → no thinking call»; a loading model is let through on purpose — a node just started would otherwise lose
  the facts of a phrase sent in its first seconds, and the vector calls wait for the load anyway.
- «Напомни через неделю» is read as a question today — step 630 (the owner's word of 2026-11-03).
