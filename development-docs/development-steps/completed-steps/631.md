## What was found (read-only on the owner's node)
- Stripe IS installed on the owner's node: `WEB4-ITEMS/core/stripe` with its build `.next-a`, passport `power.default: off` («Turn it on
  after you enter your Stripe keys»). The installer did its job.
- The left menu is built from the core's section folders `app/[lang]/(architectLayer)/architect/<id>/` (`_lib/architect-menu.ts`;
  `builtInIds()` of `lib/web4-items/built-in-elements.ts` also requires the folder). The core had no folder for `stripe` (573) nor for
  `embeddings` (626-2) — both were invisible, and nothing failed.
- `embeddings` is not on the owner's node yet: its registry is from before 626 (vectors v1.1.17, graph v1.1.24, memory v2.2.8). It
  arrives with the update — `npm run serve:rebuild` installs a missing element (`ensureElements`), and the installer rebuilds every
  element whose pinned version changed.
