## What was done
- The step he remembered is **721** (`921947b1`, `d35c5009`): its inventory was an eyes scan of 177 PAGES, and a dialog opens only on a
  click — the delete dialog printed `{address}` (the bare five-character label = the id on a node without a domain) and was never seen.
- `lib/web4-items/name-match.mjs` — `normName`, `sameName`: spaces folded, trimmed, case ignored, an empty line never matches. Pure, so
  the dialog (which only enables the button) and the door (which decides) import the same rule.
- `app/api/architect/items/[id]/route.ts` and `app/api/architect/drafts/[id]/route.ts` — `{ confirm }` must name the element:

- `delete-element-button.client.tsx` — «Удалить «{name}» насовсем?», the name to type (select-all), an empty field (no placeholder that
  reads as typed, 746-3), «Адрес в интернете: …» only when the node has a domain; `delete-draft-button.client.tsx` — «Удалить черновик
  «{name}»?» and the name. The page passes `elementLabel(item, lang)` and, with a zone, the address.
- Words: `element-settings.i18n.ts` `removeDialog` (+ `addressLine`), `web4-drafts.i18n.ts` delete words (en, ru).
- `scripts/element-name-confirm.test.mjs` (6) in the prebuild, `npm run test:name-confirm`.
