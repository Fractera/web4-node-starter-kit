«Начинай пилот 627-1 на 100 навыках»; on the first cards: «Поясни мне следующее почему-то забраковал навык в котором есть видео? Между
прочим наша платформа будет точно генерировать видео для социальной сетей и подобные навыки для генерации что видео что картинок
полезное»; «ты сказал что было 29 навыков которые несут только идеи я не понял это хорошо или плохо?»; «Я не понимаю зачем мы должны
скачивать навыки? … просто сохранить адрес репозитория?»; on cloud skills: «все что выходит из этого или конфликтует нам не нужно в
будущих навыках согласен?»; after the second run's ten cards — «Годится такой уровень, чтобы запускать разметку всех ~6 000? — go».

## What was done
- Run 1 (`b25bf9b`): `fetch` (REST, `gh`), `mark` (Haiku through `claude -p`, no tools/MCP/settings, the system prompt from a file, an
  empty temp folder), `report`, the guard `check:catalog-cards`, the planted negative control. 100 rows → 83 fetched (17 gone from
  their repositories) → 3 duplicates → 80 cards; ~$1 per 1,000 cards at the API price.
- Calibration on the way: unknowns counted as risks (both first trials «not-for-node») → risks narrowed to what harms the person.
- Run 2 (`a5f01f8`, `a641016`): two questions (`value`, `use` + `needs`), `quality` 1–5, what nodes are for (content too), local-first
  (cloud places to keep or run things → none/skip; services that only make something → with service), whole folders by batched
  sparse-checkout, scripts read, licences from the skill's folder, the partners' audits, a folder fingerprint of git blob ids.

## Proof
1. `===CATALOG_CARDS_OK=== 80 cards (value high 21, value some 43, value none 16, use install 41, use install-with-service 14, use ideas
   3, use skip 22)`; per card 7,299 input tokens mean, 908 output, 6.0 s median, $0.0016 at the API price.
2. The owner's verdict on the ten cards: «go». Negative controls: the planted skill (`curl … | bash`, ssh keys, auto-approve) →
   `use skip`, value none, quality 1, 4 risks — caught in every run; the `*/superpowers` copies with one fingerprint → one card each.

## Limits
- The marker is not deterministic on borderline skills (HeyGen `media-use`: no risk in run 2, «hides costs from the person» caught on
  the next run — its SKILL.md says so; `replica-architect`: skip, then ideas).
- `quality` gathers at 4★ (56 of 80): it separates stubs (1★) and excellent skills (5★), the middle less.

## Mistakes
- Sorting catalog results by installs; the first prompt calling unknowns risks; the first prompt describing nodes only as a web stack
  (video and image skills lowered); a fetch that wrote its record only at the end (a stopped run lost it); `checkout --pathspec-from-file`
  that fetched blobs one by one; `sparse-checkout set` replacing the patterns (an earlier run's folders wiped; the marker crashed on
  the missing file) — each fixed and written in the code where it happened.

## Evolution of skills
- Nothing to change in the skills; the marker's prompt (`scripts/catalog/marker-prompt.mjs`) carries what the owner taught it.
