**What and how.**
- **The keys of the three graph doors** (`app/api/graph-insert|query|status/route.ts`, `lib/graph/whose.mjs` `callerOf`): the node data key
  `X-Data-Secret` is the node — the shared graph and every space by its full name; an element's own key `X-Element-Key` (the graph's copy
  `lib/element-key.mjs`, word for word the stores', its test vector in `prebuild` by `scripts/check-element-key.mjs`) is that element alone;
  a presented element key is checked first, a bad one 401 `bad_element_key`. **`X-Node-Key` opens these three doors no more** (401
  `bad_key`, `WWW-Authenticate` names the two keys — `lib/graph/door.ts`); the other doors of the element keep the node key
  (`lib/node-key.ts`).
- **An element's space** (`spaceOf`): no `space` → `el-<id>`, `space: "<name>"` → `el-<id>.<name>`; a name beginning `el-` from an element →
  400 `reserved-prefix`; the node never writes under `el-` (400). **Decided on the way:** the plan wrote `el-<id>--<name>` — but a
  registry id may hold `--` (`LABEL` of `lib/web4-items/paths.cjs`), and element `a`'s space `b` would have been element `a--b`'s home; the
  dot is in no id and no name.
- `services/graph/graph.py`: the space rule takes `el-<id>[.<name>]` (one dot between two non-empty parts — no `..`), checked with
  `fullmatch` (Python's `$` let a name with a trailing newline through — an old gap of the rule); **a question to a space nobody wrote
  answers `found: false` and makes no folder** — measured on the owner's node: the empty `spaces/memory` had been made by a read.
- `graph-status` with an element key — the counts of its own spaces only, `spaces: [{ space, … }]` by its own names (`null` for the home);
  `run.mjs` `graphStatus(space)`. The card's three doors name `X-Element-Key`; README «An element's own space — and the keys», `CLAUDE.md`
  §11 «Whose spaces».
- **The node's callers on the data key:** the core's `lib/agent-kit/skills/find.mjs` (`nodeAccess` reads `DATA_SECRET`, the skills search
  and the skills base load), the memory's `lib/memory/node.mjs` `graphCall` (every graph call of the memory; its embeddings call keeps the
  node key); `lib/a2a/passport.mjs` `KEYS` takes `X-Element-Key`.
