## Systemic defects (facts and proofs; nothing fixed in the core here)

1. **The node's vectors are too weak to say «nothing fits».** The node's `embeddings` element (MiniLM-L12, 384 dimensions) scores
   unrelated short Russian queries 0.20–0.30 against the starters, while true matches score about 0.30. «бухгалтерский учёт» → post
   0.303, above the image starter's own query at 0.301; «видеомонтаж» → image 0.246 against the cut-off 0.2. The ranking is right, but
   no cut-off separates a match from no match. The store now hides this behind the OpenAI check. Every other element that searches the
   node's vectors still meets it. To research: a stronger multilingual model in the native `embeddings` (memory price on a server named
   aloud). Proof: the same 10 queries with a clear gap between matches and non-matches.
2. **«The OpenAI key is taken from the core first» (instruction §2) has no element-side road.** `lib/openai-key.ts` of native v0.1.87
   reads only `process.env` and `.env.local`. `GET /api/architect/environment` with `X-Node-Key` → 401, which is right by its gate.
   The installer never passes `OPENAI_API_KEY` to any element (`scripts/node-key-split.test.mjs:356`). Roma had to enter the same key a
   second time on the store's environment screen. Fix: either a node-key door that lets an element use the core's key without seeing
   it (a proxy, with the cost in the node's ledger), or the installer's rule. Proof: a fresh element with an empty `.env.local` makes
   an OpenAI call through the core's key.
3. **`⟦node · not-started⟧` fires for tasks queued behind a running turn.** Today I got six false alarms (14:49 ×3, 15:19, 15:20,
   15:23). Each task was queued while the store's session was busy; the 3-minute clock starts at queueing, not at pasting. Every one
   was pasted and done later. Fix: start the clock when the node pastes, or say «queued behind a running turn». Proof: two tasks in a
   row to a busy element → no alarm while its turn runs.
4. **The core cannot read an element's new session journal behind the wall.** `npm run session -- tail lidt5` → EACCES on
   `data/services/lidt5/claude/projects/…/38c79915-….jsonl` (`fe-lidt5:fractera-el`, mode 640). The older journals of that folder are
